# Política de Privacidade — Poolbot

Última atualização: 15 de Maio de 2026

## 1. Introdução

Esta Política de Privacidade descreve como o bot Pool Arkan coleta, utiliza, armazena e protege informações dos usuários ao utilizar o bot no Discord.

Ao utilizar o Pool Arkan, você concorda com esta Política de Privacidade.

---

## 2. Informações Coletadas

O bot pode coletar e armazenar informações necessárias para funcionamento adequado dos sistemas, incluindo:

* IDs de usuários do Discord
* IDs de servidores
* IDs de canais e cargos
* Configurações personalizadas do servidor
* Dados de economia, níveis e progresso
* Informações de tickets e moderação
* Preferências relacionadas aos recursos do bot

O bot não coleta senhas, e-mails privados ou dados bancários dos usuários.

---

## 3. Como os Dados São Utilizados

Os dados coletados são utilizados para:

* Executar comandos corretamente
* Salvar progresso e configurações
* Fornecer funcionalidades premium
* Melhorar desempenho e estabilidade
* Prevenir abuso, spam e uso malicioso

---

## 4. Compartilhamento de Dados

O Pool Arkan não vende, aluga ou compartilha informações pessoais com terceiros, exceto quando:

* Exigido por lei
* Necessário para segurança da plataforma
* Necessário para funcionamento técnico do serviço

---

## 5. Armazenamento e Segurança

Os dados armazenados são protegidos utilizando medidas razoáveis de segurança para evitar acesso não autorizado, perda ou alteração indevida.

Apesar disso, nenhum sistema é totalmente seguro, e não podemos garantir segurança absoluta.

---

## 6. Retenção de Dados

Os dados poderão ser mantidos enquanto forem necessários para funcionamento do bot.

Usuários e servidores podem solicitar remoção de dados quando aplicável.

---

## 7. Serviços de Terceiros

O bot utiliza serviços externos, incluindo:

* Discord
* Hospedagens e bancos de dados
* APIs e bibliotecas de terceiros

Esses serviços possuem suas próprias políticas de privacidade.

---

## 8. Direitos dos Usuários

Os usuários podem:

* Solicitar informações sobre dados armazenados
* Solicitar remoção de dados quando possível
* Parar de utilizar o bot a qualquer momento

---

## 9. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada a qualquer momento sem aviso prévio.

O uso contínuo do bot após alterações representa aceitação automática da nova política.
